# Brand assets

The BCI Workspace mark, lockups and banners. The app icon itself is generated by
`scripts/render_app_icon.swift`; the files here use the same shapes.

| File | Use |
|---|---|
| `icon.svg`, `icon-1024.png` | The app icon (tile + mark) |
| `mark-light-ring.svg`, `mark-dark-ring.svg` | The mark alone, for dark or light backgrounds |
| `lockup-dark.png`, `lockup-light.png`, `stacked-dark.png` | Mark + wordmark |
| `readme-banner-dark.png`, `readme-banner-light.png` | The top of the repo README |
| `social-preview.png` | The repository's social preview image (1280×640) |
| `avatar.png` | A square profile image |

**Name and line:** "BCI Workspace". "The whole BCI experiment. One app."

**Colour**

| Token | Hex |
|---|---|
| Navy 900 | `#0A1018` |
| Navy 700 | `#12304F` |
| Signal blue | `#5AA9FF` |
| Signal teal | `#58E0D6` |
| Ice | `#E8F3FF` |
| Slate (before the peak) | `#6F829B` |

**Type:** the wordmark and banners use [Manrope](https://fonts.google.com/specimen/Manrope)
(SIL Open Font License): "BCI" bold, "Workspace" medium. The app keeps the system font.

**Rules**
- The signal is slate before the peak and blue→teal after it, and the colour changes exactly
  at the peak.
- No glow, gloss or extra electrodes on the mark. Keep clear space of half the ring's
  diameter around it.
- Say the app "works with" a board only once that board's hardware checklist has passed
  (decision #26).
